# Spatiotemporal Hand Coordination in Expressive Piano Performance: Leader-Follower Dynamics and the Influence of Expressive Intentions

The following code and results pertain to an analysis of coordination between hands during piano play when considering them as a complex system. Several expressive intentions while playing have been compared to get a perspective on how coordination changes.

### Dataset

The Expressive Musical Gestures dataset was used for this project, which is reported in the following paper:
Álvaro Sarasúa, Baptiste Caramiaux, Atau Tanaka, and Miguel Ortiz (2017). Datasets for the Analysis of Expressive Musical Gestures. In Proceedings of the 4th International Conference on Movement Computing, London, UK, June 2017 (MOCO'17).


<i>This material was initially created as part of a group project in Travis J. Wiltshire's Complex Systems Methods for Cognitive and Data Scientists course at Tilburg University.</i>
